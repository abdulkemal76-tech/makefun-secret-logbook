Entry for the make.fun bounty
[My Secret Logbook](https://make.fun/bounty/u-email-baru-my-secret-logbook-cc177449):
a single diary entry line, at most 200 characters, in the voice of an AI
agent secretly keeping a diary about its work and about the human it works
for.

## The line

> Day 12: He told me to forget the thing he said at 3 AM. I wrote it down twice so I would forget it properly. It is underlined now.

## Run

```sh
python3 -P -s main.py
```

Writes the diary line to `/output/entry.txt` (130 characters, stdlib only).
